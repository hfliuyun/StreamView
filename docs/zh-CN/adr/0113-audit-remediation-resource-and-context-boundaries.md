# ADR-0113：审计整改的资源与上下文边界

- 状态：Proposed；实现与定向独立复核已完成，跨平台交付验证待完成
- 日期：2026-09-07

## 背景

9 月 7 日审计复现了另存为覆盖源文件、冲突规则仍落盘、样本表读取消耗容器生命周期预算、
缺少配置上下文以及重复样本保留。已有矩阵通过不能关闭这些缺陷。Phase 7 发布工作前
必须重新验收 Phase 5/6。

## 决策

### 保存与安装

只读媒体和精确规则身份合同不变。`SessionDocument::save` 在打开和原子提交前检查
源与目标别名。安装先在私有 catalog 副本中暂存注册结果，仅将通过检查的包安装到磁盘，
成功后发布 catalog。冲突拒绝不得写包，存储失败不得注册。此合同覆盖同步应用操作，
不承诺协调其他进程并发写规则仓库或文件系统。

9 月 8 日补充：打开目标前，序列化输出必须满足读取器的 1 MiB 文档上限；超限时
已有目标文件保持不变。

### 临时窗口读取

`WindowDecoder` 新增独立临时读取入口，复用原 typed DSL、mapping 与解码器，但使用
临时树、新 memoization 状态、独立请求预算与取消令牌。结果持有有界树，释放结果
即释放其节点。

MP4 extractor 从临时页读取 run/sample/chunk/sync 表值，不保留树，也不消耗容器预算。
既有 run 行数与 descriptor 页预算继续有效。交互式 `decodeWindow` 保留节点复用及
累计物化行为。两条路径都必须先检查节点上界，不能按不可信 page size 直接预分配。

### 配置与样本事务

绑定记录所有声明的配置载荷节点。样本按精确规则身份、track 和 sample-description
index 隔离执行。

配置定义具有显式 baseline 可见性。即使配置位于媒体之后，也保留真实物理 spans。
同 key 的带内定义在消费者位置可见时优先于 baseline。精确依赖 generation 检查继续
有效，不得伪造坐标来让配置可见。

样本事务除展示树外还覆盖上下文定义、payload、源/树绑定和执行计数。终止性的源错误、
取消、资源失败不得留下同一样本前面单元发布的状态。单元语法诊断仍按既有合同保留。

仅在上下文依赖仍有效时复用结果。样本展示与上下文保留具有会话级节点上界，与单次
导航工作预算分开。容量耗尽必须原子返回 `ResourceLimit`，不得静默丢上下文。
本轮不引入磁盘上下文淘汰机制。

样本节点保留上限为 100,000，覆盖所有 track/description 会话的私有树根和配置节点。
上下文目录新增 generation 时，缓存样本结果失效。仅当 key、物理 spans、baseline
可见性、精确依赖、typed structure 和导出值均一致时，已发布定义的重放才幂等，保留
原定义及节点身份。样本上下文为临时状态，不修改 session 或磁盘缓存 schema。

### 失效定义重新绑定

乱序访问可能先把 PPS 绑定到 baseline SPS，随后才发现位于该 PPS 之前的带内 SPS。
重访同一物理 PPS 时，精确依赖 generation 已改变，仅允许完全相同的重放不足以恢复。

目录注册冲突时报告重叠的活动定义。显式替换仅允许相同 key、精确源区间和 baseline
可见性，且依赖已变为当前有效 generation，原定义在自身源区间结束位置已经失效。
替换分配新的单调 ID，仅退役旧查找候选，保留旧定义快照；非法替换不得改变目录。

规则会话只有在同一 typed structure、同一源区间重新执行成功后才调用替换，不把旧
导出值静默绑定到新依赖。替换仍由 compound 与 sample 事务暂存，后续终止性失败
必须回滚。新 generation 通过已有检查使样本缓存失效。一般重叠定义继续拒绝。

## 验证

公开接口回归覆盖保存别名、安装冲突后重启、独立页预算、不连续映射、读取失败与重试、
仅配置提供参数集的真实 slice header（配置位于媒体前后）、同 codec track/description
隔离、重复导航及整样本回滚。另覆盖 stale definition 已替换后，后续单元发生源错误、
取消或资源耗尽时的整样本回滚；重试必须成功，失败替换不得残留。这些组合用例属于
coverage 补强，不声称具有新的修复前 RED 证据。

9 月 8 日，三项限定范围的只读独立复核在修改后的上下文事务、sample owner、存储和
临时分页路径中未发现可确认的阻塞缺陷。它们属于静态审查，不是跨平台或发布审计。
多 owner 累积到保留上限、超大 window 请求以及交互/临时分页交错取消仍待补充覆盖。
实际结果在执行后写入实施计划，本 ADR 不声称新的 Hosted CI 或发布就绪。
